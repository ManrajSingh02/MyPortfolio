# Developer Portfolio

A frontend-only portfolio built with React and Vite. It presents the developer's profile, resume, skills, experience, projects, and certificates.

The contact form does not require a server. It opens Gmail with a pre-addressed draft containing the visitor's details and message.

## Run locally

```bash
npm install
npm run dev
```

Update portfolio content in `src/data/fallbackData.js` and replace the resume PDF in `public/resume/` when needed.
